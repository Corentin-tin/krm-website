Un **casier automatique Mondial Relay** est installé sur le site depuis 2023.
Il fonctionne **24 heures sur 24, 7 jours sur 7**, y compris quand les
commerces sont fermés.

Vous y retirez vos colis avec le code reçu par SMS, et vous y déposez vos
retours et vos envois entre particuliers, sans file d'attente.
